# 便利なサイトの一覧

## コミュニティ系

### Qiita
コンピュータ・ソフトウェア関連の技術や情報を記録・共有するコミュニティサービス．  
2011年に当時大学生であった海野弘成らによって公開されており，日本国内のエンジニアコミュニティサービスとしては最大規模を誇る．
[Qiita](https://qiita.com/)

### Zenn
エンジニア向けの情報共有コミュニティ（ナレッジコミュニティ）サービス．  
2020年に石川俊平氏によって開発・公開されたもので，サイボウズや損保ジャパンなどの大手企業も利用している．  
[Zenn.dev](https://zenn.dev)

### Stack Overflow
2008年に開始したコンピュータ関連の情報を共有するナレッジコミュニティサービス．  
先述のQiita，Zennとは異なり英語圏で誕生したサービスであるためコミュニティの規模がかなり大きい．英語ではあるが大体の問題の解決方法が見つかる．  
英語版：[stackoverflow.com](https://stackoverflow.com)  
日本語版：[ja.stackoverflow.com](https://ja.stackoverflow.com)



## 生成AI系

## ChatGPT
OpenAI社が開発・運営する生成AIサービス．  
OpenAI社は現CEOのサム・アルトマンや，起業家のイーロン・マスクなどによって設立された．2022年11月に公開されたChatGPTは，社会に生成AIが認知される大きなきっかけを作った．  
[ChatGPT](https://chatgpt.com)

## Claude
Anthropic社が開発・運営する生成AIサービス．  
元々はOpenAIで働いていたエンジニアたちによってAnthropic社が創設され，「責任あるAI」を企業理念としている．憲法AIと呼ばれる国連の世界人権宣言やAI開発企業のガイドラインで構成されたシステムによって，人間に対して害を与える回答の生成が行われないように設計されている．  
[Claude](https://claude.ai)
