# Pythonのルール

## 命名規則
Pythonのスタイルガイド**PEP 8**では，命名規則が以下のように定められている．

|識別子|ルール|例|
|---|---|---|
|パッケージ(名前空間)|全て小文字|tokyodisneyresort|
|モジュール|全て小文字 or SnakeCase|tokyodisneyresort / tokyo_disney_resort|
|クラス|PascalCase|TokyoDisneyResort|
|型変数|PascalCase|TokyoDisneyResort|
|例外|PascalCase|TokyoDisneyResort|
|グローバル変数|SnakeCase|tokyo_disney_resort|
|パラメータ(引数)|SnakeCase|tokyo_disney_resort|
|メソッド(関数)|SnakeCase|go_to_tokyo_disney_resort|
|変数|SnakeCase|tokyo_disney_resort|
|定数|ConstantCase|TOKYO_DISNEY_RESORT|
